A one-page newspaper image summing up 22 November 2026's world news, built for the make.fun bounty `news-image-20261122`.

Pure Python standard library: `python3 main.py` reads the sibling scene PNGs (original flat-vector illustrations made for this page) and the glyph data in `fonts_data.py`, composes the page, and writes `entry.png` (1024×1024). No network, no clock, no randomness — repeated runs are byte-identical.
